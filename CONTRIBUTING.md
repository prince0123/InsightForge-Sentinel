# Contributing

Thank you for your interest in InsightForge Sentinel.

## Development Guidelines

- Follow clean architecture principles.
- Keep components modular.
- Write readable, documented code.
- Test all new features before submitting.

## Branch Strategy

- main
- feature/*
- bugfix/*

## Commit Style

Examples

feat: add health engine

fix: resolve schema inference bug

docs: update README

refactor: simplify validation engine
